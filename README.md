# analyze-CRISM-multispectral
A routine to ingest, pre-process and analyze large volumes of multi-spectral data and summary products on the CRISM data.
In short, this routine reads in CRISM multispectral summary product (spectral indices calculated from 
Viviano-Beck et al., 2014) and masks outliers. The routine also perfroms a principal component analysis coupled with a calculation to estimate variance contribution from various summary products in order to understand the suface mineralogy.
